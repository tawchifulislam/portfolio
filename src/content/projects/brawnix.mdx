## Problem

Traditional gyms manage class discovery, booking, payment, and community
engagement manually or through disconnected tools. Brawnix digitizes all of that
into a single ecosystem for members, trainers, and administrators.

## Approach

Three tier role based access control with isolated dashboards for Member,
Trainer, and Admin. Stripe powered payments built directly into the class
booking flow. A community forum with nested comment threads. A real time
analytics dashboard for admins.

## Key Decisions

- Designed the three tier RBAC system with protected routes enforced via JWT
  verification on every API request, keeping each role's dashboard fully
  isolated.
- Integrated Stripe into the booking flow while keeping checkout smooth and
  reliable, rather than bolting payment on as an afterthought.
- Implemented server side pagination, search, and category filtering directly
  with MongoDB queries so the platform stays fast as data grows.

## Outcome

The result is a working platform where three distinct user types, members,
trainers, and admins, operate through separate, protected flows on one shared
codebase.

## What's Next
