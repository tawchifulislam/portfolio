## Problem

Most weather apps feel heavier than the task needs. Meghdut is a fast, minimal lookup with no framework overhead.

## Approach

Real time conditions, a 3 day forecast, sunrise and sunset times, and city search, built with vanilla HTML, CSS, and JavaScript against the WeatherAPI.

## Key Decisions

- Handled API rate limits and error states gracefully for invalid city names.
- Built the glassmorphism UI with plain CSS, with no component library involved.
- Managed asynchronous API calls and DOM updates without a framework.

## Outcome

A lightweight, dependency free weather app with a dark, glass like aesthetic.

## What's Next

- Geolocation support to auto detect the user's city on load.
- An hourly forecast view alongside the existing 3 day forecast.
- Weather based background animations that change with conditions.
